# Team.SEE.Tutorial
This is a comprehensive overview of the Scanpy software, and is a tutorial on Scanpy as well as AnnData structure. Please install Scanpy before our class period so that you can complete the tutorial.

## Installation Instructions

### Install Scanpy

You can install Scanpy using conda or pip:

**Using conda:**
```bash
conda install -c conda-forge scanpy
```

**Using pip:**
```bash
pip install scanpy
```

For more detailed installation options and dependencies, see the [official Scanpy documentation](https://scanpy.readthedocs.io/).
